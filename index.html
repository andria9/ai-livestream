Cara Penggunaan

Sistem ini bekerja sebagai pendamping Live Studio Anda.

1. Install Aplikasi AI Livestream Host

Install aplikasi di PC/Laptop Windows Anda.

2. Install VB-Cable

Gunakan VB-Cable sebagai virtual audio untuk menghubungkan suara AI ke Live Studio.

3. Hubungkan ke TikTok Live Studio

Set input audio Live Studio ke VB-Cable.

4. Setup API AI & TTS

Masukkan API dari layanan AI & Text-to-Speech pilihan Anda.

5. Jalankan Sistem

Klik Start dan AI akan mulai bekerja saat live berjalan.
