Cara Penggunaan

Sistem ini bekerja sebagai tools pendamping Live Studio Anda

⚠️ PERHATIAN: Tools ini adalah PENDAMPING live studio, bukan pengganti total. Anda tetap perlu menjalankan live seperti biasa di TikTok/Shopee Live Studio.

1 Install Aplikasi AI Livestream Host

Download dan install aplikasi di PC/Laptop Windows 10/11 Anda. Pastikan spesifikasi memadai.

2 Install VB-Cable (Wajib)

Tools ini membutuhkan VB-Cable untuk menghubungkan suara AI ke Live Studio.
VB-Cable adalah virtual audio cable yang akan menjadi jembatan antara aplikasi AI dengan software live streaming Anda.

3 Setup Audio di Live Studio

Buka TikTok/Shopee Live Studio → Pengaturan Audio → Set input audio/microphone ke "VB-Cable Virtual Audio".
Ini memungkinkan suara AI terdengar di live stream Anda.

4 Konfigurasi API & Settings

Masukkan API key dari layanan AI (OpenAI, Gemini, dll) dan layanan Text-to-Speech pilihan Anda.
Customize prompt sesuai produk dan gaya komunikasi brand Anda.

5 Jalankan Sistem & Mulai Live

Klik "Start" di aplikasi AI Livestream Host, lalu mulai live streaming seperti biasa.
AI akan otomatis memantau chat dan merespons melalui virtual microphone.

Catatan: Pastikan koneksi internet stabil dan Anda telah menyiapkan API keys sebelum memulai.
